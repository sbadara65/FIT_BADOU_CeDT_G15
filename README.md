# FIT_BADOU – CeDT G15

Application de gestion Fitness et Renforcement Musculaire.

## Mise en ligne
1. Mettre ces fichiers dans un dépôt GitHub.
2. Ouvrir Streamlit Community Cloud.
3. Choisir le dépôt et `app.py`.
4. Déployer.
5. Copier le lien public et l'envoyer sur WhatsApp.

## Important
La base SQLite convient pour une première version/test. Pour une vraie exploitation multi-utilisateurs durable, remplacer SQLite par PostgreSQL/Supabase et ajouter une authentification Coach/Admin.
